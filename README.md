
# Radar IFCH + Concursos - GitHub Version (Caminho Rapido)

## Subir em 2 minutos

1. Crie repo vazio no GitHub: radar-ifch-concursos (publico)
2. Baixe radar-github.zip e descompacte
3. No terminal dentro da pasta:
```
git init
git add .
git commit -m "primeira"
git branch -M main
git remote add origin https://github.com/SEUUSER/radar-ifch-concursos.git
git push -u origin main
```
4. GitHub > Settings > Pages > Branch: main / root > Save
5. Link fica: https://SEUUSER.github.io/radar-ifch-concursos/
